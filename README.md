# WEB-calendar
it-проект, собственность ЛЮБА-ДРЕЛЬ


Веб-календарь
Интерактивное веб-приложение для управления событиями с поддержкой трёх видов (день, неделя, месяц), цветовой маркировкой, drag-and-drop, регистрацией пользователей и автоматической генерацией описания.




Возможности
Регистрация и аутентификация пользователей

Отображение календаря в режимах «день», «неделя» и «месяц»

Добавление, редактирование и удаление событий

Поддержка повторяющихся событий (daily, weekly, monthly) на год вперёд

Цветовая маркировка событий

Drag-and-drop перенос событий между датами

Генерация описания события через AI-endpoint

Интеграция с PostgreSQL для надёжного хранения данных

Периодическая проверка уведомлений с сервера




Технологии

Frontend

Быстрый старт
Клонировать репозиторий и перейти в каталог проекта:

git clone git@github.com:Pavuk2286/WEB-calendar.git
cd web-calendar
Создать виртуальное окружение и установить зависимости:

python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
Настроить подключение к БД в переменных окружения, например:

export DATABASE_URL=postgresql://user:password@localhost:5432/web_calendar
export SECRET_KEY="ваш_секретный_ключ"
Запустить приложение:

flask run
По умолчанию будет доступно по адресу http://localhost:5000.

Безопасность
Пароли пользователей никогда не хранятся в открытом виде. При регистрации и смене пароля используется надежное хэширование (например, через библиотеку werkzeug.security.generate_password_hash и check_password_hash), чтобы в базе данных хранились только хэши, а не сами пароли.
